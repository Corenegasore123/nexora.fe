# QuantaScope Frontend

Next.js UI for uploading building diagrams and viewing calculation results.

## Setup

```bash
npm install
cp .env.example .env
```

Set `NEXT_PUBLIC_API_URL` to your backend URL (default `http://localhost:4000`).

## Run

```bash
npm run dev
```

Open http://localhost:3000

## Requirements

The backend API must be running. See the [quantscope.be](https://github.com/Corenegasore123/quantscope.be) repository.
